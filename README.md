### About me

I'm interested in **biodiversity conservation**, **human–wildlife interactions**, and exploring ecological questions through data and small interactive tools.

我关注**生物多样性保护**与**人与自然的关系**，也喜欢用数据、可视化和小工具探索生态学问题。

<sub>Interests: Conservation · Ecology · Data visualisation &nbsp; | &nbsp; Tools: R · Python · GIS</sub>

### Selected projects

- **[Archipelago Evolution Lab](https://github.com/yunyizhang2202/Archipelago-Evolution-Lab)** — An interactive simulator exploring natural selection, genetic drift and migration across islands.
- **[Penguin Project](https://github.com/yunyizhang2202/penguin_project)** — Exploring Palmer penguins' morphometric data with R.
